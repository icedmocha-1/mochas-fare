# 🖤 Mocha's Fare Calculator

A modern, interactive fare calculator for **Diesel N' Steel**, designed to make route selection, fare calculations, and payment-change checking simple and convenient.

Built with a focus on accuracy, smooth animations, and a clean monochromatic interface.

## ✨ Features

- 🧮 **Fare Calculator** — Calculate fares using available route data.
- 🚏 **Route Selection** — Select supported origins and destinations.
- 💵 **Payment Validation** — Check payments and calculate sukli.
- ₱ **₱100 Sukli Limit** — Enforces the maximum accepted change amount.
- 🔄 **Reset Function** — Quickly reset calculator inputs and results.
- 📋 **Codes Page** — Access available codes and copy entries.
- 📰 **Updates Page** — View application updates.
- 🌑 **Dark UI** — Sleek black-and-white visual design.
- ✨ **Smooth Animations** — Transitions and interactive visual effects.
- 📱 **Responsive Design** — Designed for desktop, tablet, and mobile.
- 🔔 **Notifications** — Feedback for actions and invalid inputs.

## 🎨 Design

The interface features:

- Black and dark-gray backgrounds.
- White and grayscale typography.
- Subtle borders and highlights.
- Smooth transitions and micro-interactions.
- An animated background.
- A clean, modern layout.
